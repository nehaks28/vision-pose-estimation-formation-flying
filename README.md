Re-implementation of R. Punnoose, *"Vision-Based Precision Pose Estimation For Autonomous Formation Flying"*
(Stanford CS229, Spring 2020) with one extension from the paper's own future-work section.

## Problem
A *follower* aircraft carries a camera that always looks at a *leader* aircraft. From the pixel locations of
14 known structural features of the leader (some of which are self-occluded), estimate the relative pose
`[x, y, z, roll]` accurately enough for tight formation flight.

## Pipeline
```
 simulated detector ─► 42-d feature vector ─► ANN (42-100-100-4800) ─► coarse pose label ─┐
   (14 x [u, v, occluded])                                                                │
                                                                                          ▼
              particle filter (dynamics + reprojection likelihood, resampled from ANN label) ─► pose
              Gauss-Newton / LM reprojection refinement (ours, from ANN top-3 labels)        ─► pose
```
* **Pose discretisation** – exactly the paper's Table I: x 10 bins, y 10, z 8, roll 6 → **4800 classes**.
* **ANN** – 2×100 ReLU hidden layers, 4800-way softmax, Adam. Written in plain numpy (no DL framework needed).
* **Particle filter** – initialised from ANN label + validation error pool; propagated with the relative
  dynamics (unknown leader motion = uniform disturbance); weighted by feature reprojection error; resampling
  mixes `floor(alpha*N)` weighted particles with `N - floor(alpha*N)` drawn from the ANN label + error pool.
  Both the paper's *inverse-MSE* likelihood and a *Gaussian* likelihood are implemented.
* **Extension (ours)** – Levenberg–Marquardt minimisation of reprojection error over the 4-DoF pose
  (single-view bundle adjustment), started from the ANN's top-3 classes. The paper lists this as future work.

## Data
No dataset ships with the paper, so everything is **synthetic** and generated by `poseest/` (as in the paper):
a 14-feature aircraft model, pinhole camera (1280×960, f = 1600 px, gimballed at the leader), normal-based
self-occlusion, 0.5 px Gaussian detector noise and 2 % missed detections. Training uses 300 000 random poses
(uniform in the Table-I box, ≥ 15 m range); validation and test have 30 000 each.

## Dataset
The dataset is a **separate package** (`pose-dataset/`: `train.csv` 300k rows, `val.csv` and `test.csv` 30k each, plus its own README).
Unzip it **next to** this project folder, i.e. `Desktop/pose-formation-flight` and `Desktop/pose-dataset`.
The demo and experiments do not need it (trained weights are included); only retraining reads it.

```bash
python -m venv .venv && source .venv/bin/activate      # optional
pip install -r requirements.txt                         # numpy, scipy, matplotlib
```
